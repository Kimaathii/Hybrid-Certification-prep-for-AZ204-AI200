# Module 5 Quiz: Cosmos DB (Web + AI Edition)

## Foundation Questions (Concepts & Definitions)

**1. You are designing a global database. Which of the following best defines Azure Cosmos DB?**
A) A relational database service that requires strict schema definitions.
B) A fully managed, globally distributed NoSQL database service.
C) An on-premises graph database requiring manual server patching.
D) A file storage service for massive video files.
**Answer: B**
*Explanation:*
A is incorrect because Cosmos DB is NoSQL and schema-agnostic, not relational.
B is correct. Cosmos DB is Microsoft's fully managed, globally distributed NoSQL database.
C is incorrect because it is a cloud PaaS service, not on-premises.
D is incorrect because large blobs/videos belong in Azure Blob Storage, not Cosmos DB.

**2. What is the fundamental currency of performance used for billing in Cosmos DB?**
A) CPU Core Hours
B) Gigabytes of RAM
C) Request Units (RUs)
D) Virtual Machine Scale Sets
**Answer: C**
*Explanation:*
A and B are incorrect. Cosmos DB abstracts away underlying hardware metrics.
C is correct. Request Units (RUs) are a blended measure of CPU, Memory, and IOPS required to perform an operation.
D is incorrect. Scale sets are for IaaS VMs, not managed databases.

**3. Which property must every JSON document in a Cosmos DB container share in order to distribute data across physical servers?**
A) The primary key
B) The routing tag
C) The partition key
D) The region ID
**Answer: C**
*Explanation:*
A is incorrect. While documents have an `id`, it is the partition key that governs distribution.
B and D are made-up terms.
C is correct. The partition key is the property (e.g., `/country`) used to map logical partitions to physical servers.

**4. In the context of AI and Cosmos DB, what is a Vector Embedding?**
A) A strict SQL schema defining table relationships.
B) A mathematical array of numbers representing the semantic meaning of data.
C) A backup file created during global replication.
D) An index used exclusively for date/time searches.
**Answer: B**
*Explanation:*
A, C, and D are incorrect definitions.
B is correct. Vector embeddings are arrays of floating-point numbers generated by AI models that capture the meaning/context of text or images.

**5. What is the default consistency level for a newly created Azure Cosmos DB account?**
A) Strong
B) Bounded Staleness
C) Session
D) Eventual
**Answer: C**
*Explanation:*
A, B, and D are valid consistency levels, but they are not the default.
C is correct. Session consistency is the default. It provides "read-your-own-writes" guarantees and balances performance with availability.

## Applied Questions (How to use it)

**6. You are using the Cosmos DB .NET SDK. You want to execute a point read for a single document. Which of the following must you provide to ensure the read is efficient and doesn't scan the whole database?**
A) Only the document `id`.
B) The document `id` and the partition key value.
C) The RU limit for the query.
D) The container name and the database name only.
**Answer: B**
*Explanation:*
A is incorrect. Providing only the `id` will result in an expensive cross-partition query.
B is correct. A point read requires both the unique `id` and the partition key value so Cosmos DB knows exactly which physical server to query.
C and D are insufficient for a point read.

**7. You are building an event-driven architecture. Every time a new product is added to your Cosmos DB container, you want an Azure Function to automatically update an external Redis cache. Which Cosmos DB feature should you use?**
A) Stored Procedures
B) The Change Feed
C) Vector Indexing
D) Cross-Origin Resource Sharing (CORS)
**Answer: B**
*Explanation:*
A is for running JavaScript inside the database, not triggering external services.
B is correct. The Change Feed outputs an ordered list of inserts and updates that an Azure Function can listen to.
C is for AI searches. D is for web browser security.

**8. You are configuring a vector search in Cosmos DB for a dataset containing 20 million documents. You need sub-millisecond query performance and are willing to sacrifice a tiny fraction of absolute accuracy. Which vector index type should you configure?**
A) Flat (Brute Force)
B) B-Tree Index
C) DiskANN
D) Hash Index
**Answer: C**
*Explanation:*
A is incorrect because Flat performs an exact search against every document, which is too slow for 20 million documents.
B and D are standard relational database indexes, not vector indexes.
C is correct. DiskANN is an Approximate Nearest Neighbor index built by Microsoft designed for massive scale and speed.

**9. A developer writes a SQL query in Cosmos DB to find AI documents mathematically similar to a user's prompt. Which specific SQL function must they use in the `ORDER BY` clause?**
A) `SemanticSearch()`
B) `VectorDistance()`
C) `CosineSimilarity()`
D) `AI_Match()`
**Answer: B**
*Explanation:*
A, C, and D are incorrect or made-up function names in the context of Cosmos DB NoSQL syntax.
B is correct. `VectorDistance()` is the built-in function used to calculate the similarity between two vector embeddings.

**10. [SELECT ALL THAT APPLY] You are deploying a new Cosmos DB account for a web app that will have extreme, unpredictable spikes in traffic on random holidays, but will have zero traffic on normal days. Which of the following configurations are appropriate?**
A) Provisioned Throughput set to 100,000 RU/s.
B) Serverless Capacity Mode.
C) Partition Key of `/tenantId` (where you only have 2 tenants).
D) Partition Key of `/orderId` (where you process millions of orders).
**Answers: B, D**
*Explanation:*
A is incorrect because provisioning 100k RU/s 24/7 will cost thousands of dollars while sitting idle on normal days.
B is correct. Serverless is perfect for unpredictable, spiky traffic with idle periods.
C is incorrect. 2 tenants means extremely low cardinality, causing a Hot Partition.
D is correct. `/orderId` provides high cardinality, spreading data evenly across servers.

## Exam-Level Questions (Complex Scenarios)

**11. Contoso is migrating an on-premises application to Azure. The application requires that users in Europe read the absolute latest data written by users in the US. If the data has not finished replicating to Europe, the application must wait. Which Cosmos DB consistency level must you configure?**
A) Eventual
B) Strong
C) Bounded Staleness
D) Session
**Answer: B**
*Explanation:*
A, C, and D all allow for some degree of lag or out-of-sync reads across regions.
B is correct. Strong consistency guarantees that a read anywhere in the world will return the most recent committed version of an item. It sacrifices performance for perfect global accuracy.

**12. You are designing a multi-tenant Cosmos DB container. Tenant A generates 5 GB of data per day. Tenant B generates 10 KB per day. You chose `/tenantId` as the partition key. During peak hours, operations for Tenant A fail with a `429 Too Many Requests` error, while operations for Tenant B succeed instantly. What is the root cause?**
A) You have exceeded the total storage limit of the container.
B) Tenant A has caused a Hot Partition, maxing out the RUs on a single physical server.
C) You need to switch from the NoSQL API to the MongoDB API.
D) The consistency level is too high.
**Answer: B**
*Explanation:*
A is incorrect. Storage limits return a different error, and Cosmos DB scales storage infinitely.
B is correct. Choosing `/tenantId` grouped all of Tenant A's massive traffic onto one physical server, creating a Hot Partition that exceeded its RU limit.
C and D do not fix `429` partition limit errors.

**13. A financial trading application uses Cosmos DB. The compliance team requires that when a user views a stock ticker, the data they see must NEVER be older than exactly 5 minutes, but it does not need to be perfectly real-time. Which consistency level satisfies this requirement?**
A) Eventual
B) Consistent Prefix
C) Bounded Staleness
D) Session
**Answer: C**
*Explanation:*
A and B offer no strict guarantees on *how long* data can be delayed.
C is correct. Bounded Staleness allows you to configure a specific time window (e.g., 5 minutes) or number of versions by which reads can lag behind writes.
D only guarantees the user sees their own writes.

**14. [SELECT ALL THAT APPLY] You are implementing the Retrieval-Augmented Generation (RAG) pattern using Azure OpenAI and Cosmos DB. Which of the following steps are required in this architecture?**
A) Converting user text prompts into Vector Embeddings using an AI model.
B) Storing those Vector Embeddings inside a Cosmos DB JSON document.
C) Using the Cosmos DB Change Feed to train the OpenAI model from scratch.
D) Using `VectorDistance()` to retrieve the most relevant documents before sending them to the LLM.
**Answers: A, B, D**
*Explanation:*
A is correct. Text must be embedded to do mathematical comparisons.
B is correct. Cosmos DB natively stores these `float[]` arrays in JSON.
C is incorrect. The RAG pattern does *not* train the foundational model; it injects data into the prompt at runtime.
D is correct. Vector search is used to retrieve context before generating the final response.

**15. You write a .NET application to insert documents into Cosmos DB. Your partition key is `/category`. You execute the following code: `await container.CreateItemAsync(product, new PartitionKey("shoes"));`. If the JSON `product` object actually contains the property `"category": "electronics"`, what will happen?**
A) Cosmos DB will automatically change the JSON property to "shoes".
B) The item will be inserted into the "electronics" logical partition successfully.
C) The SDK will throw an exception because the extracted partition key does not match the one provided in the method call.
D) The item will be stored in a temporary unpartitioned state.
**Answer: C**
*Explanation:*
A, B, and D are incorrect behaviors.
C is correct. The Cosmos DB SDK enforces that the partition key value you explicitly pass in the method call exactly matches the value found inside the JSON object's partition key property. If they mismatch, the operation fails.
